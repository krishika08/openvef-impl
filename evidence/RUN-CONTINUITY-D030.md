# Run continuity, D-030 item 1 (document audit #3, D3-1)

**Not an F18 run, and not F18 evidence.** It compares two development runs on the v1.3.7 CANDIDATE pack (not audited).
Written by Claude (Claude Opus 5.5, via Claude Code), the implementation author, at Krishika's instruction (D-030).

**Question (D3-1).** Audit #2's run `run-v137c-20261127T134318Z` has `results.jsonl` SHA-256 `81c73e32…cd09`; audit #3's
run `run-v137c-20261127T153351Z` has `4b9714a4…284b`. The brief for audit #3 said "Only the pinned pack hashes differ."
The auditor could not check this because the old file was not bundled.

**Answer.** No status, category, actual or expected value differs; nor does any note, pack label or descriptor hash.
All 144 fixtures are in both files, in the same order. 135 rows are byte-identical. The other 9 rows (M07, M31, M32,
M33, M57, P01, P14, P21, P42: the only rows that carry a `simulator` field in either run, all PASS in both) differ only
in the five `simulator.l334` timing paths below. The brief's sentence was **inaccurate**: in `results.jsonl` the pack
hashes do not appear at all, and the measured timings do differ. The audit #4 brief corrects it.

**Method.** `tools/diff_runs.py` (D-030; tests in `tests/test_diff_runs.py`, synthetic vectors only) compared the two
committed files, every leaf field of every row, values compared as JSON with type. Its exit code was 0 (no critical
difference). Its report is reproduced verbatim below (SHA-256 of the report text: `8dc1943b0f58a114a5470394f17ef35a155a0966b09b58c99c3c34251802b512`); running the command
again gives the same bytes. It was run with the host Python (development tooling; it reads two committed files and
decides no fixture). Command:

```text
python3 -I tools/diff_runs.py evidence/run-v137c-20261127T134318Z/results.jsonl evidence/run-v137c-20261127T153351Z/results.jsonl
```
